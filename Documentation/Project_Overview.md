# Retail Sales Analytics SQL Project

## Project Overview

This project analyzes retail sales data using SQL to identify sales trends, customer behavior, product performance, and order patterns.

## Objectives

* Analyze overall sales performance.
* Identify top-performing products and categories.
* Understand customer purchasing patterns.
* Analyze completed, pending, and cancelled orders.
* Generate insights to support business decisions.

## Tools Used

* SQL
* SQL Server / SQL query environment
* GitHub for project documentation

## Database Tables

* Customers
* Products
* Orders
* Order_Details

## Project Status

Database creation and data loading completed. SQL analysis queries will be documented as the project progresses.
